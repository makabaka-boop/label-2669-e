# 猜数字游戏 (Bulls and Cows)

这是一个基于 Web 的经典猜数字游戏（Bulls and Cows）。玩家需要猜出一个由 3 位不重复数字组成的神秘数字。

## 游戏规则

1. **目标**：猜出系统生成的 3 位不重复数字（0-9）。
2. **反馈**：
   - **A (Bulls)**: 数字正确且位置正确。
   - **B (Cows)**: 数字正确但位置不正确。
   - 例如：答案是 456，猜 467 -> 1A1B（4 是 A，6 是 B）。
3. **难度等级**：
   - **入门**: 无限次尝试。
   - **简单**: 15 次机会。
   - **中等**: 10 次机会。
   - **专家**: 6 次机会。

## 功能特性

- 📱 **响应式设计**：完美适配 PC 和移动端。
- ⌨️ **虚拟键盘**：方便移动端输入。
- 💡 **智能提示**：基于历史猜测记录，智能分析并推荐下一个可能的答案。
- 📝 **历史记录**：清晰展示每一次猜测的结果。

## 技术栈

- HTML5 + CSS3 + JavaScript (原生)
- Docker + Nginx

## 启动方式

### 方式一：使用 Docker（推荐）

本项目配置了 Docker 环境，可以模拟真实的生产服务器环境。

**启动命令：**

在项目根目录下运行：

```bash
docker-compose up -d --build
```

**访问：**
打开浏览器访问 [http://localhost:3000](http://localhost:3000)

---

### 方式二：直接打开文件

你也可以直接用浏览器打开 HTML 文件运行游戏。

**操作步骤：**
1. 进入 `frontend` 文件夹。
2. 双击 `index.html` 文件，或者将其拖入浏览器窗口。

**优缺点分析：**
- **优点**：
  - 简单快捷，无需安装 Docker 或配置任何环境。
  - 适合快速预览和调试 UI。
- **缺点**：
  - 地址栏显示本地文件路径 (`file:///...`)，不够美观。
  - 某些依赖服务器环境的高级功能（如本地存储、跨域请求、History API 路由等）在 `file://` 协议下可能会受限（注：本项目主要使用纯前端逻辑，受影响较小）。
  - 无法体验 Nginx 部署后的真实服务器行为。

## 目录结构

- `frontend/`: 前端源代码 (HTML, CSS, JS)
- `Dockerfile`: Docker 构建文件
- `docker-compose.yml`: Docker 服务配置
